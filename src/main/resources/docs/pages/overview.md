# Overview

EB Office365Calendar connects Krista to Office 365 / Microsoft 365 calendars via the Microsoft Graph
API. Use it to manage calendars, schedule and update meetings, respond to invitations, manage
attendees, browse events, and check free/busy availability directly from Krista workflows and agents.

## Use cases

- **Manage calendars** — list, inspect, and create calendars on the connected mailbox.
- **Schedule and manage meetings** — create, update, cancel, and respond to meeting invitations.
- **Check availability** — see free/busy information for one or more mailboxes before scheduling.

## What you can do

The extension exposes 15 business-facing requests (plus the standard Setup area's Test Connection /
Health Check) grouped across three areas — see [Supported Requests](pages/supported-requests.md) for
the full list, or the sidebar for each request's detailed page.

## Before you start

1. Obtain credentials — see [Authentication](pages/Authentication.md).
2. Sign in on the **Authentication** tab (single sign-on, or your own Azure AD app credentials).
3. Run **Test Connection** (Authentication tab, or the Setup area's own Test Connection request) to
   verify connectivity.
